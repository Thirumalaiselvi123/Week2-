
# Week 2 - Factorial Program

## Project Description
This project is a simple Python program to calculate
the factorial of a given number.

## Programming Language
Python

## How It Works
1. Get a number from the user.
2. Initialize factorial to 1.
3. Multiply the numbers from 1 to the given number.
4. Display the factorial result.

## Example

Input:
5

Output:
Factorial of 5 = 120

## How to Run
Run the following command in the terminal:

python factorial.py
